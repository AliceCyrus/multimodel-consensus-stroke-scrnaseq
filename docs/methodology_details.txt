## Methodology Details (for PowerPoint)

### 1. Dataset Details
- **Source**: Raw 10X scRNA‑seq data in `StrokeData/` (add GEO/ArrayExpress ID if known).
- **Species**: Mouse (C57BL/6J).
- **Samples**: 6 biological replicates – 3 control (sham1‑sham3) and 3 stroke (mcao1‑mcao3).
- **Train/Test split**: Sample‑based, no cell leakage.
  - Training: sham1, sham2, mcao1, mcao2 (≈ 67 %).
  - Test: sham3, mcao3 (≈ 33 %).
- **Time‑point post‑stroke**: *to be specified*.
- **Cell types**: All cell types captured; QC filters applied (see below).

### 2. Pre‑processing (R – `DP_Diff_Test&Train.R`)
- **QC filtering**: `nFeature_RNA > 200` & `< 2500`; `percent.mt < 10 %`.
- **Normalization**: Seurat `NormalizeData` (LogNormalize, scale factor 10 000).
- **Variable feature selection**: `FindVariableFeatures` (vst, 3000 genes).
- **Scaling**: `ScaleData` on variable features.
- **PCA**: `RunPCA` (50 PCs retained).
- **Feature alignment**: Intersection of gene names between train and test.
- **Outputs**: `stroke_pca_train.csv`, `stroke_pca_test.csv`, `stroke_labels_train.csv`, `stroke_labels_test.csv`.
- **Initial gene count**: ~15‑20 k after QC (exact number not hard‑coded).
- **Batch correction**: None.

### 3. Train/Test Split (already defined in the R script)
- **Split ratio**: 4 train / 2 test samples (≈ 67 % train, 33 % test).
- **Cross‑validation**: 10‑fold CV with 1 000 bootstrap resamples (`comparisionModel.py`).
- **Random seed**: 42 (used for all scikit‑learn models).
- **Stratification**: Binary class balanced via `class_weight='balanced'`; CV folds stratified.

### 4. Model‑Specific Parameters
#### 4.1 Classical ML (`comparisionModel.py`)
- **Logistic Regression**: `max_iter=1000`, `solver='lbfgs'`, `class_weight='balanced'`, `n_jobs=-1`, `random_state=42`.
- **Random Forest**: `n_estimators=200`, `max_depth=20`, `min_samples_split=5`, `min_samples_leaf=2`, `max_features='sqrt'`, `class_weight='balanced'`, `n_jobs=-1`, `random_state=42`.
- **XGBoost**: `n_estimators=200`, `max_depth=6`, `learning_rate=0.1`, `subsample=0.8`, `colsample_bytree=0.8`, `eval_metric='logloss'`, `use_label_encoder=False`, `random_state=42`.

### 5. Consensus Gene Identification (`integrated_interpretability_pipeline.py`)
- **Top‑N per model**: 100 genes.
- **Consensus rule**: Gene must appear in ≥ 4 models (`min_models=4`).
- **Typical output**: ~ 65 consensus genes (depends on data).
- **Outputs**: `gene_level_results/consensus_genes.csv`, `consensus_distribution.png`.
